# 🔗 AylizDev | Linktree Bio

A modern, responsive, and minimalist "Link in Bio" landing page built with pure **HTML5**, **CSS3**, and **JavaScript**, featuring smooth glassmorphism effects and an animated splash screen.

### ✨ Features

- **Custom Splash Screen:** Smooth introductory loading animation powered by CSS transitions.
- **Glassmorphism Design:** Modern translucent card designs with backdrop blur effects.
- **Dynamic Icons:** Integrated seamlessly with [Lucide Icons](https://lucide.dev/).
- **Fully Responsive:** Optimized for mobile devices, tablets, and desktop viewports.
- **Animated Gradient Background:** Dynamic fluid background gradients.
